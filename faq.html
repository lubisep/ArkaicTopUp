Pertanyaan Umum (FAQ)

Temukan panduan lengkap dan jawaban spesifik mengenai transaksi di Arkaic TopUp.

1. Bagaimana alur lengkap transaksi top up di Arkaic?

Proses transaksi sangat cepat dan dapat dilakukan dalam 4 langkah mudah:

  • Pilih game yang ingin di-top up dari halaman utama.
  • Masukkan User ID dan Zone ID / Server akun game kamu dengan benar.
  • Pilih item/nominal diamond serta metode pembayaran (DANA atau GoPay).
  • Klik Lanjut ke Pembayaran dan lakukan transfer sesuai nominal sebelum batas waktu (30 menit) berakhir.
2. Di mana saya bisa menemukan User ID dan Zone ID akun game saya?

Buka profil di dalam aplikasi game kamu:

  • Mobile Legends: Klik foto profil di pojok kiri atas. ID terletak di bawah nama karakter, contoh: 12345678 (2001). Angka di dalam kurung adalah Zone ID.
  • Free Fire: Klik ikon profil di kiri atas. ID berupa 10 digit angka di bawah nama akun.
  • PUBG Mobile: Buka profil akun, ID numerik (8-12 digit) dapat disalin dari samping foto profil.
3. Berapa lama waktu yang dibutuhkan hingga item masuk ke akun?

Sistem kami bekerja secara otomatis 24/7. Umumnya item/diamond akan langsung masuk secara instan dalam kurun waktu 1 hingga 3 menit setelah transfer terverifikasi oleh sistem pembayaran.

4. Bagaimana jika saya salah memasukkan User ID atau Zone ID?

Pastikan kamu memeriksa kembali ID sebelum membayar. Jika ID salah tetapi akun tersebut valid milik orang lain, pesanan akan tetap terkirim ke akun tersebut dan tidak bisa dibatalkan/direfund. Jika ID tidak ditemukan oleh sistem, transaksi akan tertahan dan kamu bisa menghubungi Customer Service untuk perbaikan ID.

5. Apa saja pembayaran yang didukung dan bagaimana cara verifikasinya?

Saat ini kami mendukung pembayaran instan melalui:

  • DANA: Scan QR Code (QRIS) menggunakan aplikasi DANA.
  • GoPay: Transfer nomor ke nomor GoPay resmi kami.

Verifikasi pembayaran terjadi secara otomatis setelah transfer kamu berhasil dikonfirmasi oleh penyedia layanan e-wallet.

6. Apakah layanan top up di Arkaic aman dan legal?

Sangat aman 100%. Semua produk berasal dari distributor dan developer resmi game (100% legal). Kami tidak pernah meminta password atau data login akun kamu, cukup User ID saja.

7. Bagaimana jika batas waktu pembayaran (timer 30 menit) habis?

Jika batas waktu habis, transaksi otomatis dianggap EXPIRED / Batal. Harap jangan melakukan transfer setelah waktu habis. Jika kamu terlanjur transfer setelah status expired, segera hubungi CS kami melampirkan bukti pemotongan saldo.

8. Ke mana saya harus menghubungi jika butuh bantuan / pesanan kendala?

Kamu bisa langsung menghubungi Customer Service kami melalui WhatsApp Resmi di sidebar kiri atau via nomor +62 812-8628-3245 (Jam Operasional: 08:00 - 22:00 WIB).
